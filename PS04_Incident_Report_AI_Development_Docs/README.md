# ReportFlow — Incident Report AI

**Git Jaipur 2026 hackathon project (PS04)**

ReportFlow helps people turn an incident story into an organized draft they can review. It highlights missing details and keeps the person in control: the app does not file reports or provide legal advice.

## MVP

- Enter an incident story and organize the facts.
- Identify details the user may want to add.
- Prepare a clear draft for the user to review and copy.
- Use synthetic examples for the hackathon demo.

This is a small demo project, not a production service. Keep setup local and straightforward. No Docker, load balancer, queues, or production deployment stack is needed.

## Run locally

Use the frontend and backend instructions in their respective project folders. Keep configuration in a local `.env` file and use the mock AI provider for a demo that does not need API credentials.
